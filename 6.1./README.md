Задача 1: Средний элемент

numbers = [int(x) for x in input().split()]
С помощью генератора списка [int(x) for x in ...] мы проходимся по каждому элементу
 и превращаем текст в целые числа, сразу сохраняя их в список numbers.
Метод .split() разбивает строку на три отдельные строки по пробелам

numbers.sort()
Метод .sort() сортирует элементы списка от меньшего к большему.

print(numbers[1])
После сортировки минимальное число находится на индексе 0, максимальное на индексе 2, 
Мы выводим среднее с индексом 1 на экран.


Список выбран, потому что это изменяемая структура данных. 
Нам нужно не только хранить числа, но и менять их порядок. 

Генератор списков использован для компактного считывания данных в одну строку.

Встроенный метод sort(), выбран, поскольку элементов всего три,
 мы можем просто отсортировать их, не изобретая сложных условий.


В этой задаче на вход всегда подается строго фиксированное количество элементов. 
Количество операций не зависит от того, насколько большие эти числа. 
Чтение, создание списка из 3 элементов, сортировка (3 log 3) и вывод — 
все это выполняется за фиксированное время. Если бы нам нужно было отсортировать массив из 
N элементов, сложность была бы O(NlogN), но так как 
N=3, то есть константе, мы пишем  O(1).
